# Theorem registry

Core results of the library, keyed by the IDs of [`blueprint.md`](blueprint.md), section 4.
Statuses are defined in the [README](../README.md#statuses). Every cited declaration is
resolved in Lean's environment and audited for axioms by `scripts/AxiomAudit.lean`; its
docstring carries the exact hypotheses. The [declaration index](declaration_index.md) lists
every documented theorem. The sections below are the areas of the README
[coverage table](../README.md#coverage-at-a-glance), which `scripts/check_contracts.py --write`
generates from them.

Notation: $`\mathrm{KL}(\mu \Vert \nu)`$ is Mathlib's `klDiv μ ν` (in `ℝ≥0∞`); `tvSup` is the
library's $`\sup_A \lvert \mu(A) - \nu(A) \rvert`$ (for probability measures Mathlib's
`MeasureTheory.tvDist` is twice it); $`\Vert u \Vert_H^2 = u^\top H u`$.
